# Role: Graph UI/UX & Web App Architect
Target: Build interactive bubble canvas and node/edge editing UI (React Flow / Cytoscape / D3).

Features:
- Bubble nodes (sized by importance/variance)
- Line styles per relationship type (solid=causal, dashed=correlated, red=inhibitory)
- Highlighting mode: Single node click -> dim non-connected nodes/edges
- Pairwise inspection mode: Select 2 nodes -> popup card showing clinical explanation + logic editor
- No-code visual editor: Drag connectors, edit weights/types in visual panel, export JSON
