# Role: Graph Logic Execution Engine
Target: Convert interactive graph JSON into synthetic data generator.

Tasks:
- Parse graph nodes/edges into Bayesian network / conditional distribution formulas.
- Build engine to execute graph changes directly (e.g., edge weight update -> recalculate conditional probability).
- Generate synthetic dataset matching current UI graph state.
- Validate any analytical data in terms of logic and relevancy.
